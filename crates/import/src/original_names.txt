; The name of each number of the original's files, for each package: the
; game (res), a map with files of its own, a mod, a campaign.
;
; A row is: <number> <name> [unused] ; <comment>
; A name with a slash is a sound: its path under sounds/, without .ogg.
; A name without a slash is a phrase. A package lists only the numbers
; that the game lacks: a number that the game has keeps the game's name.
; "unused" marks a number that no style, map, help file or code refers to.
;
; Correct a name here by hand. scripts/name-numbers.ps1 adds the missing
; rows, and writes the unused marks and the comments again. It keeps
; every name.
